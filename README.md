
# Nova - Rule-Based AI Chatbot 🤖

## Project Overview
Nova is a beginner-friendly rule-based AI chatbot developed using Python. It interacts with users through text-based conversations and responds to predefined commands and questions.

The chatbot uses conditional statements, functions, loops, and string handling to understand user input and provide appropriate responses.

## Features
- Responds to greetings such as Hello, Hi, and Hey.
- Answers basic questions about itself.
- Tells the current time.
- Displays today's date.
- Shows conversation message count.
- Provides a help menu with available commands.
- Responds to thank-you messages.
- Handles unknown inputs.
- Supports exit commands such as Bye, Exit, and Quit.

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python chatbot.py
```
